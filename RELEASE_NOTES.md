## GROMACS 2026.3 CUDA build for Google Colab

### Intended environment

- Linux x86-64
- Google Colab
- NVIDIA T4 GPU
- CUDA-enabled GROMACS 2026.3
- Educational molecular dynamics laboratories

### Included assets

- `gromacs_cuda_build.tar.gz`: precompiled installation tree
- `SHA256SUMS.txt`: SHA-256 integrity checksum

### Important

This is an unofficial educational build. It is not a native Windows
application and should be executed inside a compatible Google Colab
Linux runtime.
